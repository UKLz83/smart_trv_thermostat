# Smart TRV Thermostat

Custom Home Assistant integration for virtual TRV thermostat control.

## Install with HACS
1. Add this repository as a custom repository in HACS.
2. Choose category **Integration**.
3. Download the integration from HACS.
4. Restart Home Assistant.
5. Go to **Settings -> Devices & Services -> Add Integration** and search for **Smart TRV Thermostat**.
